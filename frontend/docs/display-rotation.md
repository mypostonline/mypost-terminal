# Поворот интерфейса терминала

Если Chromium открыт на весь экран в горизонтальном разрешении, а монитор установлен вертикально, задайте в `frontend/.env`:

```env
VITE_ROTATE=left
```

Если изображение перевёрнуто, используйте `right`. Для обычного отображения задайте `none` или удалите переменную. Адрес терминала менять не нужно.

Для локального запуска перезапустите `npm run dev` после изменения `.env`. Для собранного приложения выполните `npm run build` и обновите раздаваемые файлы: переменные `VITE_` встраиваются при сборке.

Этот режим помещает терминал в отдельную область браузера с портретными размерами и поворачивает её целиком. Всплывающие окна и закреплённые кнопки остаются внутри этой области. После включения проверьте касания на самом устройстве: системную калибровку сенсора интерфейс не меняет.
